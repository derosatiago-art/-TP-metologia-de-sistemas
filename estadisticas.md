Creá varios archivos para explicar los comandos (por ejemplo, comandos-basicos.md o manejo-de-ramas.md). Acordate de redactarlos con tus propias palabras. Podés agrupar los que tengan funcionalidades similares

git shortlog -s -n (Este comando lista a todos los autores del repositorio ordenados de mayor a menor cantidad de commits.)

git rev-list --merges --count HEAD (Te devuelve un número entero exacto con la cantidad de merges que hay en el historial.)
